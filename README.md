# 기출지우개 : 공인중개사 2027

'기출 지우개'(https://jjangguss-prog.github.io/gichul-jiugae/)의 사본(처음 이름 '기출 지우개 2'). 지금 앱은 37회(2026-10-31)까지의 공부 기록으로 그대로 두고, 바꾸는 건 여기서 한다.

- 주소: https://jjangguss-prog.github.io/gichul-jiugae2/
- 11-02: **오늘 탭만 매일 하면 시험 전에 다 지우게.** 하루 분량을 시간(15분~2시간)으로 고르지 않고 시험일에서 거꾸로 정한다.
  - 새 카드: 남은 새 카드를 새 카드 마감일(시험 45일 전, 지금은 2027-09-15)까지 남은 날로 나눈 몫(지금 하루 32장). '시작'을 여러 번 누르거나 다른 기기에서 해도 그날 본 새 카드를 뺀다. 못 한 날이 있으면 다음 날부터 저절로 조금씩 늘고, 앞서 본 만큼은 줄어든다. 지금 과목 새 카드가 몫보다 적게 남으면 과목 순서대로 다음 과목에서 잇는다.
  - 복습은 그날 나올 카드를 전부 낸다. 예전엔 '시작'마다 0.7×분으로 잘리고 틀린 수 많은 것부터라, 한 번에 맞힌 카드가 뒤로 밀려 지워지지 않았다. 지운 카드 검사는 '시작' 횟수와 상관없이 하루 3장.
  - 오늘 탭은 '오늘 할 것'(복습·새 카드·검사 수와 걸릴 시간)과 완주 계획(새 카드 하루 몫·과목별·전부 끝나는 날)을 보여 준다. 다 보면 오늘 틀린 카드를 '이어서'로 한 번 더 내고, 다 했으면 '✓ 오늘 할 것을 다 했습니다'와 '새 카드 앞서 보기'를 띄운다. 카드 화면 시계는 걸린 시간.
  - 실제 앱 코드로 11-02부터 시험 전날까지 돌려 본 결과(카드 10,067장): 예전 방식은 60분이면 37%, 2시간이어도 86%만 지웠다. 바꾼 뒤엔 매일 하면 9/21에 전부 지우고(하루 140장 안팎), 열흘에 하루·네 날에 하루를 빠져도 9/26에 전부 지운다(빠진 날 뒤엔 그만큼 많아진다).
- 11-01 밤: 이름을 '기출지우개 : 공인중개사 2027'로. 켤 때 지우개가 낙서를 지우며 이름이 드러나는 첫 화면(누르면 건너뜀). 카드에서 잘못 누른 것(O/X·🤔·다음 등)은 '↶ 되돌리기'로 바로 전 선택부터 하나씩 되돌린다(PC는 Ctrl+Z).
- 11-01: **38회 1차·2차 동차용 짜임.**
  - 과목 다섯: 1차 학개론·민법, 2차 중개사법·공법·공시세법. 위쪽은 38회(2027-10-30 예정, 공고가 나오면 바꿈)까지 남은 날.
  - 매일 하는 건 '오늘' 하나. 아래 탭은 오늘·현황·자료·설정 넷이고, 패턴·개념·논점·타시험 목록·실전은 '자료' 한 곳에 모았다.
  - 새 카드는 한 과목씩(1회독은 한 과목을 쭉 보고 다음 과목으로: 중개사법 → 공법 → 공시세법 → 민법 → 학개론, 새 카드가 남은 과목만). 복습·지운 카드 검사는 모든 과목에서 섞여 나온다. 오늘 탭 과목 표를 누르면 새 카드 과목이 바뀐다.
  - 지우기: 서로 다른 날 3번 연속 맞히면 지운다(하루에 한 번만 센다). 지운 카드는 하루 3장씩 몰래 다시 나와 틀리면 되살아난다.
  - 예상 점수·판단 정확도는 1차·2차 따로(과목 40점 미만 과락, 차수마다 평균 60점).
  - 2차 카드: 중개사법·공법·공시세법 32~36회 600문항 → 카드 2,573장. 선지마다 근거와 법령 조문 원문(국가법령정보센터), 문항마다 '실무에서는'. 근거는 38회 시험일에 시행 중일 법 기준이고, 출제 뒤 법이 바뀐 곳은 '법 개정 주의'를 띄우며 정오가 바뀐 선지는 지금 법 기준 답으로 낸다. 표 문항은 표로 보인다.
  - 근거가 별표·서식(업무정지 기준, 확인·설명서, 건축물 용도 분류 등)인 곳은 법제처 별표·서식 원문을 인용한다. 확정답안이 전항 정답인 문항(33회 공시세법 6번)은 실전 탭에서 아무 답이나 맞게 채점한다.
  - 2차 타시험: 2차 범위와 겹치는 다른 시험의 2025·2026년 기출 154문항(카드 674장)을 같은 근거 틀(38회 시험일 기준 법, 조문 원문)로 넣어 공법·공시세법 새 카드 사이에 고르게 섞는다. 감정평가사 1차 감정평가관계법규·주택관리사보 2차 주택관리관계법규(큐넷, 공공누리), 법원직 9급 부동산등기법(법원행정처), 지방직 9급 지방세법·국가직 9급 세법개론(인사혁신처 국가공무원 채용시스템). 2027년 시험은 나오는 대로 더한다.
  - 확인 안 된 것은 해설에 '❔ 확인 안 됨'으로 적는다: 2027년 개정을 봐야 아는 것, 큐넷 확정답안을 못 본 것, 판례·등기예규·등기선례 원문과 대조하지 않은 근거.
  - 카드 자료는 판(cards.ver, 파일 내용으로 정함)이 바뀔 때만 새로 받는다. 해설만 고쳐도 판이 바뀐다.
  - 27~31회 기출(11-01 밤): 1차 학개론·민법 400문항(카드 1,674장)과 2차 세 과목 600문항(카드 2,647장)을 더해 1차·2차 모두 27~36회 10년치가 됐다(전체 10,067장). 같은 근거 틀이고 민법도 조문 원문을 붙였다. 출제(2016~2020년) 뒤 법이 바뀐 선지는 지금 법 기준 답과 '법 개정 주의'로 내고, 제도가 없어져 지금 법으로는 물을 수 없는 7문항은 카드 없이 실전 탭에만 둔다. 정답은 두 출처(풀고패스 문항 페이지·전자문제집 CBT)를 맞댔고, 확정답안이 복수정답·전항 정답인 문항은 실전 탭에서 그대로 채점한다. 2차 논점 등급은 10년치라 1차와 같이 4회 이상 A급.
  - 해설 읽기 쉽게: 판단 틀은 줄마다 나눠 줄머리를 굵게, '외우기' 줄은 노란 띠로. 조문 원문에서 해설 결론과 같은 말에 형광(카드 4장 중 3장꼴). 2차 해설의 기간·금액·인원·비율 숫자는 굵게, 선지 번호(①·ㄱ)는 색. 논점·출제 의도·실무에서는 이름은 상자 위 한 줄로. 모두 앱이 그릴 때 저절로 칠해서, 근거를 고쳐도 다시 칠할 일이 없다.
- 10-31: 타시험 논점을 O/X 카드로 진도에 섞었다. 2026년 8개 시험(감정평가사·주택관리사·공인노무사·행정사·세무사·법원직 9급·법무사·변호사시험)이 먼저 낸 민법·부동산학 논점을 옳은 문장(O)·출제자가 한 자리를 바꾼 틀린 문장(X) 한 쌍으로 만들어 새 카드에 고르게 섞어 낸다. 같은 논점의 O·X는 다른 때 나온다.
