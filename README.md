# 기출 지우개 2

'기출 지우개'(https://jjangguss-prog.github.io/gichul-jiugae/)의 사본. 지금 앱은 37회(2026-10-31)까지의 공부 기록으로 그대로 두고, 바꾸는 건 여기서 한다.

- 주소: https://jjangguss-prog.github.io/gichul-jiugae2/
- 바뀐 것(10-31): **타시험 논점을 O/X 카드로 진도에 섞었다.** 2026년 8개 시험(감정평가사·주택관리사·공인노무사·행정사·세무사·법원직 9급·법무사·변호사시험)이 먼저 낸 민법·부동산학 논점을 옳은 문장(O)·출제자가 한 자리를 바꾼 틀린 문장(X) 한 쌍으로 만들어, 오늘 탭의 새 카드에 기출 카드와 고르게 섞어 낸다. 같은 논점의 O·X는 다른 때 나온다. 판정·지우기(3번 연속 맞히면 지움)·지우기 시험·뒷면 근거는 기출 카드와 같고, 뒷면에 나온 시험·공인중개사 출제 회차·다른 시험이 바꿔 낸 꼴이 붙는다.
- 기록은 지금 앱과 따로 둔다. 같은 주소(jjangguss-prog.github.io) 아래라 기기 저장소를 함께 쓰기 때문에, 저장 이름을 모두 `jiugae2`로 바꿨다. 기기 간 동기화도 다른 파일(`jiugae2-sync.json`)에 한다.
- 설정 → **지금 앱 기록 가져오기**: 그 기기의 지금 앱 기록을 한 번 옮겨 온다(지금 앱 기록은 읽기만 한다). 기출 카드는 본 데까지 이어지고 타시험 카드는 새 카드로 남는다.
- 그 밖의 기능(패턴·개념·타시험 탭·듣기·실전·5문제만)은 지금 앱과 같다. 듣기 오디오는 지금 앱과 같은 오디오 저장소를 쓴다.
- 문제: 한국산업인력공단 큐넷 공개 기출문제(공공누리 출처표시). 선지 근거·타시험 O/X 문장: 이 앱을 위해 직접 작성.
