# 기출 지우개 2

'기출 지우개'(https://jjangguss-prog.github.io/gichul-jiugae/)의 사본. 지금 앱은 37회(2026-10-31)까지의 공부 기록으로 그대로 두고, 바꾸는 건 여기서 한다.

- 주소: https://jjangguss-prog.github.io/gichul-jiugae2/
- 11-01: **38회 1차·2차 동차용 짜임.**
  - 과목 다섯: 1차 학개론·민법, 2차 중개사법·공법·공시세법. 위쪽은 38회(2027-10-30 예정, 공고가 나오면 바꿈)까지 남은 날.
  - 매일 하는 건 '오늘' 하나. 아래 탭은 오늘·현황·자료·설정 넷이고, 패턴·개념·논점·타시험 목록·실전은 '자료' 한 곳에 모았다.
  - 새 카드는 한 과목씩(1회독은 한 과목을 쭉 보고 다음 과목으로: 중개사법 → 공법 → 공시세법 → 민법 → 학개론, 새 카드가 남은 과목만). 복습·지운 카드 검사는 모든 과목에서 섞여 나온다. 오늘 탭 과목 표를 누르면 새 카드 과목이 바뀐다.
  - 지우기: 서로 다른 날 3번 연속 맞히면 지운다(하루에 한 번만 센다). 지운 카드는 하루 3장씩 몰래 다시 나와 틀리면 되살아난다.
  - 예상 점수·판단 정확도는 1차·2차 따로(과목 40점 미만 과락, 차수마다 평균 60점). 2차 카드는 만드는 중.
  - 카드 뒷면에 '법 개정 주의'를 띄울 자리(2차는 해마다 법이 바뀐다).
- 10-31: 타시험 논점을 O/X 카드로 진도에 섞었다. 2026년 8개 시험(감정평가사·주택관리사·공인노무사·행정사·세무사·법원직 9급·법무사·변호사시험)이 먼저 낸 민법·부동산학 논점을 옳은 문장(O)·출제자가 한 자리를 바꾼 틀린 문장(X) 한 쌍으로 만들어 새 카드에 고르게 섞어 낸다. 같은 논점의 O·X는 다른 때 나온다.
- 기록은 지금 앱과 따로 둔다. 같은 주소(jjangguss-prog.github.io) 아래라 기기 저장소를 함께 쓰기 때문에, 저장 이름을 모두 `jiugae2`로 바꿨다. 기기 간 동기화도 다른 파일(`jiugae2-sync.json`)에 한다.
- 설정 → **지금 앱 기록 가져오기**: 그 기기의 지금 앱 기록을 한 번 옮겨 온다(지금 앱 기록은 읽기만 한다).
- 문제: 한국산업인력공단 큐넷 공개 기출문제(공공누리 출처표시). 선지 근거·타시험 O/X 문장: 이 앱을 위해 직접 작성.
